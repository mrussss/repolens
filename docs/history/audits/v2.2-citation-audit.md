# v2.2 Citation Failure Audit

Audit input: `artifacts/realbench/20260920T144804Z-1481bc63`.

This report is read-only with respect to the artifact, frozen dataset, and
Ground Truth. It records the five `INVALID` citations from the pre-Evidence-ID
runner and correlates each one with the Agent trace and the cached snapshot.

## Summary

| Case | Invalid citations | Classification |
|---|---:|---|
| REAL-001 | 2 | LINE_OFFSET, CITED_RANGE_NOT_OBSERVED |
| REAL-002 | 2 | EXCERPT_REWRITE |
| REAL-003 | 1 | EXCERPT_REWRITE |

All five failures had a matching `read_file` or `search_code` tool call in the
trace. The old protocol allowed the model to reconstruct a path/range/excerpt
from a large or truncated tool response, so these are protocol failures rather
than evidence that the snapshot validator should be relaxed.

## Detailed records

```json
  "actual_excerpt": "lines 85-95 finish WriteHeader; basicWriter.Write starts at line 96 and line 100 is the ResponseWriter.Write call",
  "validation_error": "excerpt does not match actual file lines in snapshot",

  "tool_result_truncated": false,
```

The model cited a function start and body shifted upward by eleven lines. The
actual counter increment is at line 112, not in the cited end line 100.

The model inserted ellipses into source text. The requested source range was
available in the tool result; the invalidity was caused by rewriting the
excerpt, not by a missing range.

### REAL-002 / citation index 1

```json
  "actual_excerpt": "The snapshot contains the complete Traverse loop; the cited range includes the switch cases at 827-847 and the recursive call at 857",
  "validation_error": "excerpt does not match actual file lines in snapshot",
  "matching_tool_call_found": true,
  "tool_requested_range": "search_code command.go followed by read_file path=command.go start_line=821 end_line=860",
  "tool_result_truncated": false,
  "category": "EXCERPT_REWRITE"
}
```

Again, `...` was model-authored compression. It is not a valid canonical
excerpt and must not be accepted by a citation validator.

### REAL-003 / citation index 2

```json
{
  "case_id": "REAL-003",
  "citation_index": 2,
  "path": "client.go",
  "start_line": 183,
  "end_line": 283,
  "model_excerpt": "The excerpt contains `// ... other cases ...` and omits the intervening source cases",
  "actual_excerpt": "The snapshot contains the full getBodyReaderAndContentLength switch through line 282, including []byte, bytes.Buffer, bytes.Reader, io.ReadSeeker, io.Reader, nil, and default cases",
  "validation_error": "excerpt does not match actual file lines in snapshot",
  "matching_tool_call_found": true,
  "tool_requested_range": "read_file path=client.go start_line=183 end_line=285",
  "tool_result_truncated": false,
  "category": "EXCERPT_REWRITE"
}
```

The trace shows an earlier full-range request and a later bounded request. The
later result was bounded by the tool output budget, and the model additionally
rewrote omitted cases as `...`; the model-generated citation therefore cannot
be treated as a source range.

## Phase 0 conclusion

All five invalid citations are classified. None is a validator false negative,
and this audit does not modify the frozen RealBench cases, Ground Truth, or
the original artifact.
